LATENCY & THROUGHPUT DEFINITION
------------------------------------------------------------------------------------------
  Latency  = wall-clock time to process 1 BATCH (ms/batch)
  Batch size used = 128
  → batch_size=128: latency covers 128 images processed in parallel (GPU)
     Use Throughput (img/s) for per-image comparison across platforms.
  Throughput = total_images / total_time_seconds  (img/s)
  START: tensors enter model forward()
  END  : output exits model + torch.cuda.synchronize() (if CUDA)
  NOTE : image I/O and tensor host→device transfer excluded from timing

HW MONITORING METHODOLOGY
------------------------------------------------------------------------------------------
  Each model runs ALL batches sequentially (pass-per-model).
  Background thread polls every 50 ms.
  Reported values = aggregate over all samples in that model's pass.
